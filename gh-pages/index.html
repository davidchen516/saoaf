THE OPERATING IDEA

Sovereignty is the ability to change without losing control.

01

Choose

Use logical capabilities, rather than hard-coded models, tools, agents, clouds, or endpoints.

02

Connect

Use MCP, A2A, OpenAPI, CloudEvents, OCI, and OpenTelemetry where each protocol belongs.

03

Control

Keep policy, identity, delegated authority, evidence, and lifecycle decisions explicit.

04

Replace

Prove that a provider, agent, tool, or deployment zone can be changed through tested contracts.

RUNTIME FLOW

Plan centrally. Execute directly.

  1. 01

    Declare capabilities

    An Agent Harness sends structured requirements and sovereignty constraints.

  2. 02

    Resolve a plan

    The Resource Router returns providers, profiles/actions, contract versions, and a short-lived plan ID.

  3. 03

    Call direct data planes

    The Harness invokes MMR, Context, MCP, or A2A endpoints directly.

  4. 04

    Link evidence

    Model route, tool execution, agent task, and policy decision IDs remain traceable without copying payloads.

GET STARTED

Start with one narrow, verifiable capability path.

The first production slice should be small enough to audit and meaningful enough to prove replacement and governance.

1

Publish a capability

Define a stable capability ID, owner, risk level, data classification, and contract version.

tool.erp.work-order.read
2

Register a provider

Publish a signed logical profile or action snapshot. Do not expose credentials or internal instances.

enterprise-mcp-gateway
3

Bind and resolve

Create an environment-specific binding. Resolve it into a short-lived Resource Plan at runtime.

POST /resource-plans:resolve
4

Run an exit drill

Switch to an alternate provider and verify the same capability works with the same Agent contract.

provider A → provider B

GOVERNANCE

Open protocols do not replace accountable control.

  • Identity & Trust makes authentication, authorization, delegation, and approval decisions.
  • The Resource Router carries constraints; specialist gateways enforce decisions at execution time.
  • The control plane stores metadata and evidence references, never prompts, tool parameters, credentials, or model responses.
  • Every critical provider needs an owner, contract, lifecycle, and tested exit path.

CONTRIBUTE

Help make enterprise AI portable by design.

Architecture

Propose a boundary, ADR, threat model, or reference deployment that preserves domain authority.

Contracts

Add capability schemas, provider snapshots, compatibility fixtures, or protocol conformance tests.

Adapters

Build thin, replaceable adapters for MMR, MCP, A2A, Context, and AI Factory integrations.
