# GitHub Pages homepage

This folder is a dependency-free, bilingual public homepage for the Sovereign AI & Open AI Fabric open-source reference architecture.

It is ready for GitHub Pages through the workflow in `../.github/workflows/deploy-pages.yml`.

## Publication steps

1. Push this repository to GitHub.
2. In **Settings → Pages**, select **GitHub Actions** as the source.
3. Push to `main`, or run **Deploy GitHub Pages** manually from Actions.
4. GitHub will publish the contents of this folder to the repository Pages URL.
