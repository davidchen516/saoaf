# I02 红运行④：密钥泄露 → gitleaks 门禁拦截

- 工具：本地 gitleaks 8.30.1（与 CI gitleaks-action 相同规则集）
- 注入物：随机生成的 AWS 格式假密钥（垃圾值，仅存在于 /tmp 探针 worktree，从未进入仓库）
- 注意：gitleaks 默认 allowlist 排除文档示例键（含 "EXAMPLE" 字样），因此探针必须使用随机格式键——CI 探针分支因此 redo

$ gitleaks detect --source . --redact
INF 16 commits scanned.
INF scanned ~503193 bytes (503.19 KB) in 76ms
WRN leaks found: 1

gitleaks exit code 非零（检测到泄露即失败）。CI 侧同规则的 gitleaks-action 红运行记录见探针分支 run 链接（Issue #2 关闭时回填，取证后删除探针分支）。
